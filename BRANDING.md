# Mithril logo

The canonical mark is `resources/mithril-mark.svg`, copied without changes from
`https://mithril.fund/assets/mithril-mark.svg` on 2026-10-02. It is the blue
crystal and sparkle on a dark rounded square used by the public site's favicon.

Web and Desktop import `@mithril/design-system/mithril-mark.svg` at build time.
Keep onboarding, chat, loading, profile, provider and About surfaces on this
asset. Do not introduce inline replacement emblems or redesign it during UI
work. The mark stays bundled for offline use; do not load the website at runtime.
Native PNG/ICO/ICNS assets use the same crystal artwork at packaging sizes.
Logo changes require an explicit branding request and updates to both consumers.
